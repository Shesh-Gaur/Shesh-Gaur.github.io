    <h2>Overview</h2>

    <p>
    6Degrees is a third person action-adventure game where players transfer their mind into a variety of Robots in order to battle foes, traverse the environment, and solve puzzles all while having to protect their physical body from harm.
    </p>

    

    <p>Currently in Development by <a href="https://www.instagram.com/codebluegames" target="_blank">Code Blue Games</a></p>

<div class="postbody">
    <h2>Info</h2>
    <ul>
    <li>Currently in development using Unreal Engine 5. Developed gameplay systems using C++ and Blueprints. Worked with Unreal's Gameplay Ability System (GAS) to implement features.</li>

    <li>Implemented and improved several locomotion systems: Swimming compatible with <a href="https://imaginaryblend.com/2025/01/10/fluid-flux-documentation" target="_blank">Fluid Flux</a>, Walking/Hanging on Beams, <a href="https://www.instagram.com/reel/DHoTwxLueN-/?utm_source=ig_web_copy_link&igsh=MWo2MGk5Z2ZqN2sxNw==" target="_blank">Free Climbing</a> between different surfaces, support for <a href="https://www.instagram.com/reel/DJwtdx9NWdy/?utm_source=ig_web_copy_link&igsh=YzRkZHJwN29wamd6" target="_blank">moving targets</a> with the climbing systems, etc.</li>
    
    <li>Nativized systems made in BP to C++, implemented optimizations</li>

    <li>Implemented animations, set up state machines in an Animation Blueprint, and state variables in a C++ AnimInstance to ensure <a href="https://dev.epicgames.com/documentation/en-us/unreal-engine/animation-optimization-in-unreal-engine#animationfastpath" target="_blank">Fast Path optimization</a>. Set up hand and feet IK for features using Control Rigs. Implemented animation related features using Motion Warping and Animation Notifies.</li>

    <li>Worked on physics based systems like Rope Swinging, Telekinesis. Focused on making systems framerate independent through Substepping, Async Physics Tick, etc.</li>

    <li>Worked with designers to improve and iterate on features. Helped diagnose issues and fix bugs</li>
    </ul>
</div>
